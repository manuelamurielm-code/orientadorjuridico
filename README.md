Una plataforma interactiva de **LegalTech** diseñada para traducir situaciones cotidianas a conceptos jurídicos sencillos en Colombia. Orienta al usuario sobre sus derechos, normas aplicables, mecanismos de acción y autoridades competentes con fines puramente pedagógicos.

# Enlace a la Landing: https://manuelamurielm-code.github.io/orientadorjuridico/

## ✨ Características Principales

* **Traducción Jurídica Inteligente:** Simulación interactiva de análisis legal mediante inteligencia artificial.
* **Internacionalización (i18n):** Soporte completo multi-idioma sin recargas (Español, Inglés y Portugués de Brasil).
* **Tema Claro / Oscuro:** Interfaz adaptable al gusto del usuario con un diseño "Glassmorphism" elegante.
* **Diseño Responsivo:** Visualización óptima en dispositivos móviles, tablets y escritorio.
* **Recursos Prácticos:** Pestañas interactivas con Casos Frecuentes, Mecanismos de Acción (Tutela, Derecho de Petición) y un Glosario Cotidiano.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilos avanzados, variables CSS (Custom Properties), animaciones e interfaz gráfica pastel/tierra y modo oscuro.
* **Vanilla JavaScript:** Lógica de negocio, gestión de idiomas (i18n), Intersection Observer para animaciones al hacer scroll y simulador interactivo de chat legal.

## ⚠️ Aviso Legal

> **Importante:** Esta aplicación proporciona únicamente orientación informativa y pedagógica. Las respuestas o simulaciones no constituyen asesoría legal profesional ni sustituyen la atención de un abogado certificado. Para decisiones legales definitivas, acude siempre a las autoridades competentes (Personería, Defensoría, Consultorios Jurídicos).
